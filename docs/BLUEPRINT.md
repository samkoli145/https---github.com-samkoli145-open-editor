# BLUEPRINT — المخطط المعماري المرجعي

> **الغاية:** بوابة فهم مقصد المشروع لخططي المنتج/البنية والوافدين الجدد.
> **قاعدة التحرير:** نقطي فقط، بلا فقرات، بلا إسهاب، بلا تكرار — إحالة للمستندات الأم.
> **المستندات الأم:** السورس الكامل `kernel.md` · الحالة الجارية `docs/architecture.md` · السجل `docs/changelog.md` · خطة الحالة `PLAN.md`.

## 1. المقصد (جملة واحدة)

نواة تشغيل محلية (Agentic OS Kernel) تدير النظام كأنه توزيعة Arch — ملفات، برامج مثبتة، أوامر، وLLM محلية — بصلاحيات **حتمية** (لا ذاتية) وطبقات أمان إلزامية، تُدار عبر أوامر نواة + REST، بلا سحابة.

## 2. الركائز

- **محلي أولاً** — لا اعتماد خارجي؛ `@google/genai` حُذف (§5-ط).
- **حتمية بدل ذاتية** — البوابات قرارات آلة لا رأي LLM (POSIX/allowlist/حصص).
- **طبقات أمان متعددة** — الخارجي لا يلمس الداخلي إلا عبر بوابة.
- **مكوّن واحد لكل مسؤولية** — نواة P · نواة عليا AgentKernel · مستضيف Bootloader · نظام VFS.
- **قابل للربط** — أي مكوّن يسجّل أوامر في CommandRegistry (host.\* · agent.\* · launcher.\* · tool.\*).

## 3. حماية الموارد (من الخارج إلى الداخل)

1. **REST**: `X-API-Key` إلزامي لكل `/api` + مقارنة ثابتة الزمن (`timingSafeEqual`) + تدقيق `/api/audit` (register/activate/emit/launch/scan/execute…).
2. **طبقة تنفيذ أرش** `LinuxArchExecutionLayer`: code-domain → allowlist (70+) → حصص (معدل/زمن/أخطاء) → جذر تنفيذ realpath → ELF (e_ident/e_type + SHA-256) / shebang (مفسّر من allowlist) → حظر المفسِّرات العامة (LOLBins) → TOCTOU re-check.
3. **صندوق تنفيذ** `ExecutionSandboxEngine`: بوابة POSIX/ملكية/فهرس ثم توجيه فعلي للطبقة الأرشية (§5-م).
4. **VFS/فهرس دائم**: SHA-256 موحّد · حفظ ذرّي (tmp+rename) · غلاف بصمة يرفض العبث `EINTEGRITY` · تتبّع `linkTarget` للسيملينك ورفض الهروب (§5-طـ).
5. **حساب آمن**: أداة `calc` بمحلّل خاص بلا `eval` (§5-ز) · تخزين بمفتاح مُنقّى وحيد (§5-د) · سجل مسارات معقّم.
6. **حصص موارد** `ResourceQuotaGuard`: حد توكنات/زمن/أخطاء لكل وكيل؛ تجاوز → `EQUOTA_EXCEEDED`/`EOM`.
7. **مراقبة**: كمون إشارة مُقاس فعلياً (§5-ب) · تدقيق كل أمر حساس.

## 4. ترتيب التشغيل (نقاط متتالية)

1. `Bootloader` → اختيار بروفايل + تحميل إعداد.
2. تركيب VFS (ذاكرة + قرص آمن).
3. `new Kernel()` (نواة P).
4. نظم فرعية: AgentKernel (LLM + tools + حصص + جلسات) · Hermes · Snowball · Editor — كلٌّ يربط أدواته.
5. `kernel.boot()` → تسجيل أوامر host → الحالة `running` (ميزانية إقلاع <500ms).
6. **[server فقط] مشغّل البرامج**: `LauncherManager` يسجّل `launcher.launch/stop/list` في النواة؛ اكتشاف البرامج المثبتة **عند أول طلب** (كسلان) لا في الإقلاع.
7. تشغيل: `executeSyscall` → بوابة صلاحيات → CommandRegistry → تنفيذ حتمي.
8. Shutdown: إلغاء pendingSyscalls (`ECANCELED`/`EKILLED`) → تفكيك VFS.

## 5. بنية المكونات

| طبقة | موقعها | مسؤولية |
|---|---|---|
| نواة P | `src/kernel/` (11 ملفاً) | سجل أوامر · EventBus · جدولة · صلاحيات |
| مستضيف | `src/host/` | إقلاع · بروفايلات · VFS · مشغّل · محرر/Orchestrator · كرة ثلج |
| نواة عليا | `src/agent-kernel/` | LLM (Deterministic/Ollama/اكتشاف محلي) · tools · حصص · جلسات · طبقة أرش |
| نظام | `src/system/` | VFS/فهرس · تخزين آمن · صندوق تنفيذ |
| خادم | `server.ts` | REST + لوحة تحكم RTL · مصادقة/تدقيق |

## 6. شروط كتابة/صيانة هذا المستند

- **نقطي حصراً** — لا فقرات، لا سرد، لا أمثلة؛ أقصى عمق: عنوان + نقاط.
- **أرقام التحقق إلزامية** — كل تعديل معماري يحدّث رقم `npm test` (الحالي: **331/332**؛ الوحيد الفاشل بيئي Firefox).
- **الإحالة لا التكرار** — التفاصيل في المستندات الأم؛ هنا المخطط والبوابات والترتيب فقط.
- **كل بوابة أمنية جديدة تُضاف للقسم 3** بترتيب الخارج→الداخل.
- **كل خطوة تشغيل جديدة تُدرج في القسم 4** بنفس الترقيم المتتالي.
- **المصطلحات ثابتة** — اسم الوحدة بالإنجليزية + وصف عربي موجز.
- **لا تُحذف بنداً دون إبقاء أثره** في changelog/PLAN.
- **متى يتغير**: تغيير مقصد/بوابة/ترتيب تشغيل/بنيان — عدا ذلك يُترك هذا الملف.

## 7. بوابة الفهم (المقصد في ستة أسطر)

- نظام يستبدل «رأي الوكيل» بـ«قواعد الآلة».
- كل تنفيذ يمر ببوابات إلزامية متعددة، لا بأذن واحدة.
- كل شيء محلي أولاً؛ الشبكة خيار مقيّد بمفتاح.
- كل مكوّن يقدّم نفسه أوامرَ للنواة — لا قنوات جانبية.
- المحصلة: وكيل ينفّذ فعلياً (لا يحكي أنه ينفّذ) داخل حدود صارمة.
- المرجع الأعلى للتفاصيل: `kernel.md` · `docs/architecture.md` · `docs/changelog.md`.
